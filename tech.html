Projects & Tools

Open-source work, side projects and the technical stack I rely on day to day. All source code is on GitHub.

fluxgate

GitHub ↗

A lightweight, embeddable pub/sub broker written in Rust. Supports persistent topics, consumer groups and at-least-once delivery without a ZooKeeper dependency.

Rust async tokio networking

cue-check

GitHub ↗

A CLI tool that validates Kubernetes manifests against CUE schemas, integrates with pre-commit hooks and outputs structured diagnostics for CI pipelines.

Go CLI Kubernetes CUE

lambdac

GitHub ↗

A pedagogical compiler for a simply-typed lambda calculus extended with algebraic data types and pattern matching, targeting LLVM IR. Accompanies my M.Sc. thesis.

Rust LLVM type theory compilers

k8s-starter

GitHub ↗

Opinionated Terraform + Helm starter kit for production-ready Kubernetes clusters on AWS EKS, including Prometheus, Loki and automated TLS with cert-manager.

Terraform Kubernetes AWS Helm

logview

GitHub ↗

Terminal log viewer that parses JSON structured logs, filters by severity and field predicates, and renders them with readable colour-coded output.

Rust TUI JSON observability

raft-kv

GitHub ↗

Educational implementation of the Raft consensus algorithm with a replicated key-value store. Includes leader election, log replication and membership change.

Go Raft distributed systems
